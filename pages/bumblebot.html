Description

BumbleBot Garden App is PWA that assists home gardeners keep track of their plants. It was built with WaspJS, a fullstack JS framework that leverages a React front end with a SQL database using Prisma. Using the plant API, Perenual, users can search for plants, then save them to their own gardens for reference later. This specific app shows my ability to use and create APIs.
